Ghil Labs Gmail Automation

Ghil Labs가 운영자 본인의 Gmail 계정을 정리하기 위해 만든 개인용 자동화 도구입니다. 일반 사용자에게 제공하는 서비스가 아니며, 사용자는 운영자 1명뿐입니다.

하는 일

  • 흩어져 있던 Gmail 라벨을 소수의 상위 라벨로 통합합니다.
  • 운영자가 승인한 발신자 목록에 따라 Gmail 필터를 만들고, 안 읽는 발신자의 메일을 받은편지함에서 격리 라벨로 옮깁니다.
  • 90일 넘게 읽지 않은 메일을 격리하고, 운영자가 차단하기로 승인한 발신자의 격리 메일만 30일 뒤 휴지통으로 보냅니다. 영구 삭제는 하지 않습니다.
  • 매주 1회, 운영자 본인에게 정리 현황 요약 메일을 보냅니다.

접근하는 데이터

메일 본문과 제목은 읽지 않습니다. 발신자 주소, 구독 해지 헤더 유무, 라벨, 수신 날짜 같은 메타데이터만 사용합니다. 자세한 내용은 개인정보처리방침을 참고하세요.

Overview (English)

Ghil Labs Gmail Automation is a personal tool built and operated by Ghil Labs to organize the operator's own Gmail account (label consolidation, filters, quarantine of long-unread senders, and a weekly summary email to the operator). It is not offered to the public and has a single user: the operator. It uses message metadata only and does not read message bodies or subjects. See the Privacy Policy.
