개인정보처리방침

운영자: Ghil Labs · 시행일: 2026-10-01 · English version below

1. 이 도구에 대해

Ghil Labs Gmail Automation은 Ghil Labs가 운영자 본인의 Google 계정 1개를 정리하기 위해 만든 개인용 도구입니다. 일반에 공개된 서비스가 아니며 사용자는 운영자 1명입니다. 다른 사람의 Google 계정 데이터는 처리하지 않습니다.

2. 요청하는 Google 권한과 용도

  • gmail.modify: 라벨 목록 조회·생성, 메일의 라벨 추가·제거, 운영자가 승인한 차단 발신자의 격리 메일(격리 30일 경과분)을 휴지통으로 이동, 운영자 본인에게 주간 요약 메일 발송. 메일 영구 삭제와 라벨 삭제는 하지 않습니다.
  • gmail.settings.basic: 운영자가 승인한 규칙에 따라 Gmail 필터를 조회·생성.

3. 접근하는 데이터

메일 본문과 제목은 읽지 않습니다. 다음 메타데이터만 사용합니다: 발신자(From) 주소, 구독 해지(List-Unsubscribe) 헤더의 유무, 라벨 ID, 수신 날짜, 라벨·필터 목록, 계정 이메일 주소(요약 메일 수신처 확인용).

4. 저장과 보관

  • 데이터는 운영자가 직접 운영하는 서버(n8n)와 운영자의 개인 컴퓨터에서만 처리·보관됩니다.
  • 정상 종료된 작업의 실행 기록은 서버에 저장하지 않습니다. 오류로 끝난 작업의 기록에는 디버깅을 위해 발신자 주소가 일시적으로 남을 수 있으며 운영자가 삭제할 수 있습니다.
  • 운영자의 개인 컴퓨터에는 발신자별 집계표와 변경 내역이 저장되며 외부에 공개하지 않습니다.

5. 제3자 제공·공유

Google 사용자 데이터를 판매하거나 광고에 사용하지 않으며, 제3자에게 제공하지 않습니다. 단, 주간 요약 메일의 짧은 코멘트를 만들기 위해 AI 모델 API(Anthropic)에 도메인 단위의 집계 수치(예: 도메인 이름, 건수, 안 읽은 비율)만 전송합니다. 발신자 주소 전체, 메일 본문, 제목은 전송하지 않습니다.

6. Google API 서비스 사용자 데이터 정책

이 도구가 Google API를 통해 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

7. 접근 해제와 삭제

운영자는 언제든 Google 계정 권한 페이지에서 이 앱의 접근을 해제할 수 있으며, 서버의 자격증명과 로컬 파일을 삭제하면 보관 중인 데이터가 제거됩니다.

8. 문의와 변경

문의: GitHub Issues. 이 방침이 바뀌면 이 페이지에 반영하고 시행일을 갱신합니다.

Privacy Policy

Operator: Ghil Labs · Effective: 2026-10-01

1. About this tool

Ghil Labs Gmail Automation is a personal tool built by Ghil Labs to organize the operator's own single Google account. It is not offered to the public, has one user (the operator), and does not process any other person's Google account data.

2. Google permissions requested and why

  • gmail.modify: list and create labels; add or remove labels on messages; move quarantined messages from operator-approved blocked senders (after 30 days in quarantine) to Trash; send a weekly summary email to the operator's own address. The tool never permanently deletes messages and never deletes labels.
  • gmail.settings.basic: list and create Gmail filters according to rules approved by the operator.

3. Data accessed

The tool does not read message bodies or subjects. It uses only metadata: sender (From) address, presence of the List-Unsubscribe header, label IDs, received date, label and filter lists, and the account email address (to address the summary email to the operator).

4. Storage and retention

  • Data is processed and kept only on the operator's own self-hosted server (n8n) and the operator's personal computer.
  • Execution data of successful runs is not stored on the server. Records of failed runs may temporarily contain sender addresses for debugging and can be deleted by the operator.
  • Per-sender summary tables and change records are stored on the operator's personal computer and are not published.

5. Sharing with third parties

Google user data is not sold, used for advertising, or shared with third parties. The only exception: to write a short comment in the weekly summary, domain-level aggregate figures (domain name, counts, unread ratio) are sent to an AI model API (Anthropic). Full sender addresses, message bodies, and subjects are not sent.

6. Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deletion

The operator can revoke this app's access at any time on the Google Account permissions page; deleting the server credentials and local files removes the retained data.

8. Contact and changes

Contact: GitHub Issues. Changes to this policy will be posted on this page with an updated effective date.
